LEVEL UP 365 — версия 2: автоматический ежедневный план

Что добавлено:
- Автоматическое создание ежедневного плана начиная со 2-го дня программы.
- Каждый день появляется 6 базовых заданий по пяти направлениям; на недельном обзоре или при хорошем выполнении может добавляться 7-е дополнительное задание.
- План создаётся только для текущей даты. Задания следующего дня не появляются заранее.
- Нагрузка мягко адаптируется к выполнению автоматических заданий предыдущего дня.
- Автоматические задания помечены «Автоплан · День ...».
- Существующие задачи, цели и заметки сохраняются: ключ локального хранилища прежний.
- Резервное копирование включает также историю создания автопланов.

Важно:
- День 1 намеренно оставлен без изменений, чтобы не смешивать новый план с уже созданными вручную задачами первого дня.
- Ежедневные задания создаются в браузере на устройстве при первом открытии приложения в соответствующий день. Если в этот день приложение не открывать, уведомление само по себе не придёт.
- Push-уведомления на iPhone в этой версии НЕ реализованы. Для них понадобится отдельная настройка web push и серверная часть.
- Цели остаются долгосрочными и личными: приложение автоматически формирует ежедневные шаги, но не придумывает за пользователя жизненные цели.
- Данные хранятся локально в браузере. Перед обновлением экспортируйте резервную копию из раздела «Итоги» на всякий случай.

Обновление GitHub Pages:
1. Откройте репозиторий level-up-365 на GitHub.
2. Выберите Add file -> Upload files.
3. Извлеките архив и загрузите содержимое папки LEVEL_UP_365 (не сам ZIP) поверх существующих файлов.
4. Убедитесь, что index.html лежит в корне репозитория.
5. Нажмите Commit changes.
6. На iPhone закройте приложение, откройте сайт в Safari и обновите страницу. Если старая версия ещё показывается, полностью закройте веб-приложение и откройте снова через Safari.

Сохранение данных:
- Код использует прежний localStorage ключ levelup365-v1, поэтому задачи/цели/заметки текущей версии должны остаться на том же устройстве и в том же браузере.
- Не очищайте данные сайта и не удаляйте веб-приложение до экспорта резервной копии.
- Не загружайте JSON-резервные копии в публичный репозиторий.
