LEVEL UP 365 — первая версия

Что уже работает:
- добавление и удаление задач;
- категории задач;
- отметка выполнения;
- список личных целей;
- ежедневная заметка;
- базовая статистика;
- экспорт и импорт резервной копии;
- адаптация под экран iPhone;
- PWA manifest и service worker для установки на домашний экран.

ВАЖНО:
Данные хранятся локально в браузере на текущем устройстве. Не очищайте данные сайта, пока не сделали экспорт резервной копии.
В этой версии нет облачной синхронизации и автоматических push-напоминаний. Для настоящих уведомлений на iPhone потребуется отдельная настройка и публикация PWA по HTTPS; поддержка web push на iOS зависит от версии системы и установки на домашний экран.

Запуск на Windows:
1. Распакуйте архив.
2. Для простого просмотра откройте index.html в браузере. Сохранение задач будет работать, но установка PWA и офлайн-режим могут не работать при открытии как file://.
3. Для установки на iPhone сайт нужно разместить на HTTPS-хостинге (например, GitHub Pages). Затем открыть адрес в Safari -> Поделиться -> На экран «Домой».
4. Не публикуйте личные заметки в публичном репозитории.

Это стартовый прототип, не финальная версия.
